# 天安门广场 · 三维漫游

> **在线浏览**：https://bai795.github.io/tiananmen-square-3d/  
> **GitHub 源码**：https://github.com/bai795/tiananmen-square-3d  
> **离线下载**：[天安门广场-3D网页.zip](./天安门广场-3D网页.zip)

一座可以在浏览器中自由漫游的天安门广场三维写生。整个场景由代码程序化生成，纹理也全部由 Canvas 实时绘制，不依赖任何外部图片、模型或字体文件。

## 打开方式

直接双击 **`index.html`** 即可离线浏览，不需要安装依赖或启动服务器。推荐使用最新版 Chrome / Edge / Safari（需支持 WebGL 2）。

如果双击后没有反应，或是在聊天窗口、编辑器、网盘等**应用内预览**中打开，请改为双击 **`打开天安门广场.bat`**：它会自动寻找本机的 Chrome / Edge 并打开页面。也可以右键 `index.html` → 打开方式 → Google Chrome。

### 打开后一直显示 0%？

0% 表示当前窗口**没有开始执行页面脚本**，并不是模型正在缓慢加载。常见原因是应用内预览禁用了 JavaScript，或使用了兼容模式 / 过旧的浏览器。请用系统浏览器打开，不要停留在应用内预览。

页面需要 JavaScript 与 WebGL 2。如果 WebGL 不可用，会显示“场景未能展开”的提示；这与 0% 不同。仍然无法打开时，按 `F12` 打开开发者工具，把 Console 中的第一条红色错误发来即可定位。

## 分享给别人

- **离线发送**：直接发送 [`天安门广场-3D网页.zip`](./天安门广场-3D网页.zip)。压缩包约 190 KB，内含 `index.html`、`使用说明.txt` 和 Windows 启动脚本；对方解压后打开即可。
- **只发网页**：也可以只发送 `index.html`。所有样式、脚本和纹理都已内联，不需要附带其他文件。
- **在线链接**：如果对方主要用手机或微信，建议把 `index.html` 上传到任意静态托管服务（如 Netlify Drop、GitHub Pages、Vercel），然后把生成的网址发过去。手机的文件管理器通常只会预览本地 HTML，不执行脚本。
- 不要把整个项目文件夹发给别人；只需要分享包或 `index.html`。

## 场景内容

- **北端**：天安门城楼、五券门、重檐歇山顶、金水河与五座石桥、华表、石狮、红墙、宫城背景
- **广场**：五星红旗与旗杆、人民英雄纪念碑、毛主席纪念堂、东西两侧的人民大会堂与中国国家博物馆、人民广场铺装与绿化
- **南端**：正阳门（前门）
- **环境**：中轴景观、北京老城肌理、远山与城市灯火、程序化云层与星空

## 交互

- 拖拽旋转 · 滚轮缩放 · 右键平移
- 点击左侧轴线导览或场景中的编号地标，查看图文介绍并飞往近景
- **自动巡游**：按中轴线依次浏览八个地标
- **切换夜景 / 白昼 / 黄昏**：日夜光照循环切换；夜里可以看到亮起的城楼、星图与月亮
- **俯瞰广场**、**回到开场**：快速切换视角
- 键盘：`R` 回到开场，`N` 切换光影，`空格` 开始/暂停巡游，`Esc` 关闭面板

## 技术与说明

- Three.js / WebGL 2；ES module 源码经 esbuild 打包为单文件内联脚本
- 自定义的中式屋顶曲面、斗拱、栏杆、城台与券门构件
- 实时阴影、可动画旗帜、水面波纹、程序化天空（云、星空、日月）、昼夜光照过渡
- 场景按公开资料进行**艺术化重建**，建筑比例与细部经过取舍，不是测绘级复原
- 源码位于 `src/`，`vendor/` 内保留了运行时与构建所需的 Three.js 文件

## 重新构建

在项目目录运行：

```bash
node build.mjs
```

构建脚本会调用 esbuild，把 `src/` 中的页面、样式与脚本打包生成新的 `index.html`。如果本机没有对应版本的 esbuild，可通过环境变量 `ESBUILD_BIN` 指定可执行文件路径。
